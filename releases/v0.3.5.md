# Waxlight Launcher v0.3.5

## What's New

* 🌐 **Public Server Browser** — browse public Vintage Story servers directly inside Waxlight, view server details, save favorites and connect using any of your instances.
* ❤️ **Favorite Servers** — save servers together with the instance you normally use and quickly reconnect later.
* 🖱️ **Mouse Back/Forward Navigation** — side mouse buttons now work throughout the launcher for going back and forward between pages.
* 🔑 **Launcher no longer becomes unusable when the system credential store is locked or unavailable** — Waxlight can start normally and retry credential access later.
* 📦 **Better instance package imports** — imports now appear in Operations with live progress and can be cancelled safely.
* 🐛 **Various fixes around mods, imports, launching and general launcher stability.**
