# Waxlight Launcher v0.4.0

Waxlight 0.4.0 brings a major interface refresh, more control over how your game is launched, and several improvements for Linux users.

## What's New

- ✨ **Refreshed UI & UX** — Waxlight's interface has been reworked around a new unified design system, making pages, dialogs, buttons, inputs, tabs, toolbars, cards, loading states, and navigation more consistent throughout the launcher.

- ⚙️ **Per-Instance Environment Variables** — instances can now define their own environment variables directly from the instance settings. They are passed to Vintage Story when the game starts and can be used for GPU selection, driver configuration, debugging, runtime options, and other advanced setups.

  Example:

  ```text
  KEY=value
  ```

  This works on both **Windows and Linux** and does not require modifying game scripts or launcher shortcuts.

- 🐧 **Better Linux Desktop Integration** — Waxlight no longer overwrites user-customized `.desktop` entries when registering `waxlight://` links. The URL handler is now managed separately, so custom launch options and environment configuration are preserved.

- 📦 **Improved Linux Portable Package** — the portable Linux archive now includes clearer instructions for getting Waxlight running and using the included launcher scripts.

## Improvements

- 🎨 More consistent spacing, typography, controls, dialogs, navigation, and page layouts across the application.
- 🧭 Improved visual consistency between Library, Mods, Servers, Operations, Statistics, Settings, Accounts, and Versions.
- ♿ Shared controls and navigation have received accessibility and interaction improvements.
- 🛠️ Various internal stability, migration, packaging, and release-process improvements.

## Important

Waxlight 0.4.0 upgrades the launcher database to a newer schema.

After starting 0.4.0, **older versions of Waxlight may no longer be able to open the upgraded database**, so downgrading to an earlier release is not recommended.
