# Waxlight Launcher v0.5.2

## New

- Added **favorite mods** — mods can now be bookmarked directly from the catalog or mod details page.
- Added a dedicated **Favorites** tab for quickly finding saved mods.
- Favorites are stored locally and persist between launcher restarts.

## Improvements

- Improved mod and instance card actions by moving controls over the cover artwork for a cleaner layout.
- Updated frontend dependencies with security fixes and general maintenance improvements.
