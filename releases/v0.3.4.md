# Waxlight Launcher v0.3.4

## What's New

- 💾 **Instance Backups** — create and restore snapshots of your instances at any time.
- 🛡️ **Automatic Safety Backups** — Waxlight creates restore points before mod updates, removals, and game version changes.
- 🔄 **Smart Recovery** — after a failed game launch, Waxlight can show what changed and offer to restore the last working setup.
- 📦 **Batch Mod Installation** — select multiple mods and install them all into an existing or new instance at once.
- 🧹 **Mod Cache Cleanup** — safely remove unused downloaded mod files to free disk space.
- 🐛 **Better Error Reporting** — game crashes and launcher errors are now captured more reliably, making troubleshooting easier.
- ✨ Various fixes and improvements to mod installation, dependencies, settings, and overall stability.
