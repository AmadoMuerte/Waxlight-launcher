# Waxlight Launcher v0.3.6

What's New
⚡ Optimum Support — Waxlight can now launch instances using an existing Optimum installation. Optimum can be detected automatically or selected manually, and Waxlight checks that it matches the Vintage Story version used by the instance before launching.
🎮 Per-Instance Game Client — individual instances can now use either the standard Vintage Story client or Optimum while keeping the same mods, saves, settings and launch arguments. Existing instances continue using Vanilla by default.
🪟 Fixed Windows Installation Cancellation — cancelling a Vintage Story installation on Windows now correctly stops the installer process instead of potentially leaving it running in the background.
🐛 Various fixes and stability improvements.

Enjoy the game! ❤️
