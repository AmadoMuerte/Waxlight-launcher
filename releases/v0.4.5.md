# Waxlight Launcher v0.4.5

This release focuses on better mod management, Linux compatibility, diagnostics, and performance.

## What's New

### Mod update policies

Mods can now use individual update policies:

- **Pin** — keeps the currently installed version.
- **Compatible** — updates only to versions compatible with the current game version.
- **Automatic** — always uses the latest available version.

These settings are preserved when cloning, importing, or exporting instances.

### Configurable backup retention

You can now choose how many automatic snapshots Waxlight should keep.

Older automatic snapshots are removed when the limit is reached. Manual snapshots are never deleted automatically.

### Problem reports

Waxlight can now create and submit diagnostic reports directly from the launcher.

You can review exactly what will be sent before submitting it. Sensitive local information is sanitized, and successful reports receive an ID that can be shared when asking for support.

### Better .NET detection on Linux

Detection of the .NET 10 runtime required by current Vintage Story versions has been improved.

Waxlight now handles system, user, Snap, symlinked and custom runtime installations more reliably and provides clearer errors when a compatible runtime cannot be found.

### Faster mod browser

The mod catalog has received several performance improvements:

- fewer unnecessary network requests;
- caching of recently loaded data;
- more efficient mod card rendering;
- improved cover image loading.

Browsing and switching between mod pages should now feel noticeably faster.

### Operations history

The Operations history now uses its own scrollable area instead of continuously expanding the page.

## Other changes

- Improved diagnostics for early Vintage Story launch failures.
- Added detected .NET information to support logs.
- Improved handling of instance environment variables.
- Updated translations and internal APIs.
- Various stability and UI improvements.
