# Обновления лаунчера

Контролируемые обновления: каналы stable и prerelease, проверка контрольных сумм и подписей.

## Как это работает

1. При включённой проверке обновлений Waxlight запрашивает GitHub Releases и, при наличии обновления, его ассет `SHA256SUMS`.
2. После выбора «Скачать и установить» лаунчер загружает установщик и проверяет его SHA-256 по данным релиза.
3. На Windows дополнительно требуется валидная Authenticode-подпись от настроенного доверенного издателя — только после этого запускается установщик.

Автоматическая проверка обновлений включена по умолчанию и выполняется при старте лаунчера; отключается в **Настройки → Обновления**. Доступен выбор канала: стабильный или prerelease.

## Модель доверия

> [!WARNING] SHA-256 ≠ подпись издателя
> `SHA256SUMS` подтверждает, что файл совпадает с опубликованным хэшом, но не удостоверяет издателя: тот, кто заменит и файл, и контрольную сумму, подсунет совпадающий вредоносный файл.

Authenticode даёт аутентификацию издателя и целостность после подписи — но только когда Waxlight знает ожидаемого издателя (subject сертификата или отпечаток). Если закреплённый издатель отсутствует, файл не подписан, подпись невалидна или издатель не совпадает — обновление **отклоняется**.

## Текущий статус подписи

Windows-релизы в настоящее время не имеют цифровой подписи. Поскольку доверенный Windows-издатель не настроен, Windows-сборки **отклоняют автоматическую установку обновлений** после проверки контрольной суммы. Обновляйтесь вручную со страницы [GitHub Releases](https://github.com/AmadoMuerte/Waxlight-launcher/releases/latest).

Подробности — на странице [«Подпись кода»](../policies/code-signing.md).

## Режимы установки

Обновлятель определяет режим установки в рантайме. Портативные Windows-копии не заменяются автоматически; установленные копии получают установщик только после инициирования обновления пользователем. Хелпер обновления ждёт выхода Waxlight, запускает установщик тихо и пытается перезапустить лаунчер.

## SmartScreen и MOTW

Обновлятель **не использует** `Unblock-File`: удаление Mark of the Web обходит защиту SmartScreen. Ручные загрузки сохраняют обычное поведение Windows с MOTW и SmartScreen.
