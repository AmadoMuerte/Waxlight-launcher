# Моды и ModDB

Встроенный браузер Vintage Story ModDB: поиск, установка, обновление и управление модами для каждого инстанса.

## Каталог ModDB

Раздел «Моды» обращается к официальному каталогу Vintage Story ModDB:

- поиск и фильтры по каталогу;
- страница мода с описанием, версиями и чейнджлогами;
- установка выбранной версии мода в конкретный инстанс;
- пакетная установка модов.

## Управление модами инстанса

- установка из каталога и из локальных файлов;
- включение/выключение без удаления;
- обновление и удаление;
- моды, установленные вручную, отображаются наравне с каталожными (помечаются как локальные).

## Анализ обновлений

Waxlight умеет проверять, какие моды инстанса можно обновить через каталог. Проверка («обновления модов» инстанса) строит отчёт по каждому установленному моду:

| Статус | Значение |
| --- | --- |
| `up_to_date` | Установленная версия совпадает с кандидатом из каталога |
| `update_available` | Есть более новая версия; указаны целевые ID и версия |
| `not_updatable` | Нельзя обновить через каталог: локальный мод, отсутствует в каталоге или ошибка каталога |
| `unknown` | Состояние определить не удалось |

Для кандидата на обновление выбирается версия по приоритету: помеченная каталогом как latest → новейшая стабильная → новейшая любая. Отчёт дополнительно показывает:

- **совместимость** — поддерживает ли кандидат версию игры инстанса (информационно, обновление не блокируется);
- **новые зависимости** — которых ещё нет в инстансе;
- **удалённые зависимости** — которые новой версии больше не нужны;
- чейнджлоги и признак prerelease.

> [!NOTE] Отчёт — не действие
> Анализ ничего не скачивает и не изменяет в инстансе. Обновление применяется явным действием пользователя через обычный поток загрузки каталога.

Технические детали библиотеки анализа: [modpack.md](https://github.com/AmadoMuerte/Waxlight-launcher/blob/main/docs/modpack.md).
