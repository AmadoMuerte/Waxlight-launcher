# Пакеты инстансов

Экспорт и импорт инстансов в виде переносимых пакетов Waxlight — чтобы делиться сборками и переносить их между машинами.

## Что такое пакет

Пакет Waxlight — это архив инстанса, который можно передать другому пользователю или импортировать на другом компьютере. Пакет содержит файлы инстанса: моды, конфиги, настройки — всё, что нужно для воспроизведения сборки.

## Очистка приватных данных

При экспорте пакет автоматически санитизируется. Из него исключаются:

- `sessionkey`, `sessionsignature`, `playeruid`, `playername` из `clientsettings.json`;
- MP-токены, пароли, секреты системного хранилища, токены аутентификации;
- прочие аккаунт- и машинно-специфичные настройки.

> [!TIP] Можно делиться
> Пакет не содержит учётных данных: получателю понадобится собственный аккаунт Vintage Story, чтобы играть на импортированной сборке.

## Импорт

При импорте пакета Waxlight разворачивает инстанс в библиотеку. После импорта выберите для инстанса аккаунт и при необходимости версию игры — и можно играть.
