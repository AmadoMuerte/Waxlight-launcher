# Операции и загрузки

Все длительные задачи — загрузки и установки версий игры — на одной странице: прогресс, отмена, история.

## Статусы

| Статус | Состояние |
| --- | --- |
| `queued` | В очереди (активная) |
| `running` | Выполняется (активная) |
| `completed` | Завершена успешно |
| `failed` | Завершена с ошибкой |
| `cancelled` | Устаревшая запись из старых версий лаунчера |

## Отмена — это откат

Успешная отмена операции не оставляет записи в истории. Waxlight:

1. отменяет контекст операции и ждёт остановки загрузчика/установщика;
2. удаляет `<файл>.partial` и `<файл>` из каталога `downloads/`;
3. удаляет строку операции из базы и публикует событие `operation:removed`;
4. освобождает блокировки и завершает вызов отмены.

Если очистка файлов не удалась, операция помечается `failed`, а вызов возвращает ошибку — запись специально остаётся, чтобы показать проблему и дать повторить удаление после исправления прав.

## Докачка

Официальные пакеты игры скачиваются в `downloads/<имя>.partial`. После проверки контрольной суммы файл переименовывается без `.partial`. При сетевой ошибке частичный файл сохраняется — следующая попытка продолжит с места обрыва, если CDN поддерживает HTTP Range.

## История

- Активные операции можно только отменить.
- Завершённые — удалить по одной (с подтверждением) или очистить всю историю разом.
- Удаление активных операций запрещено на уровне базы данных: защита работает даже против некорректного клиента.
- Список отсортирован от новых к старым и ограничен 100 записями.
