# Политика подписи кода

Windows-релизы в настоящее время не имеют цифровой подписи.

Официальные артефакты релизов Waxlight собираются GitHub Actions из тегированных коммитов публичного репозитория и публикуются в [GitHub Releases](https://github.com/AmadoMuerte/Waxlight-launcher/releases/latest). Каждый релиз содержит `SHA256SUMS` для проверки целостности.

`SHA256SUMS` подтверждает совпадение загрузки с контрольной суммой релиза, но не удостоверяет издателя. Неподписанные Windows-сборки могут вызывать предупреждение Microsoft Defender SmartScreen.

В будущем Waxlight может добавить подпись Windows-кода. Если это произойдёт, политика и релизный конвейер будут обновлены с описанием фактического механизма подписи.

Скачивайте Waxlight только с официальной страницы GitHub Releases. О проблемах безопасности, связанных с происхождением релизов, подписью или чувствительными данными, сообщайте через [политику безопасности](./security.md).
