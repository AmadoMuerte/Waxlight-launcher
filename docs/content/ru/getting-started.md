# Быстрый старт

От скачивания до запуска игры — несколько минут.

## Скачивание

Официальные сборки публикуются **только** на странице [GitHub Releases](https://github.com/AmadoMuerte/Waxlight-launcher/releases/latest). Каждый релиз включает файл `SHA256SUMS` для проверки целостности загруженных файлов.

| Платформа | Пакет | Файл |
| --- | --- | --- |
| Windows x64 | Установщик (с ярлыками и деинсталлятором) | `*-windows-amd64-installer.exe` |
| Windows x64 | Портативная версия (без установки) | `*-windows-amd64-portable.zip` |
| Debian / Ubuntu x64 | Пакет .deb (Debian, Ubuntu, Mint и совместимые) | `*-linux-amd64.deb` |
| Fedora / RPM x64 | Пакет .rpm (Fedora и RPM-совместимые) | `*-linux-amd64.rpm` |
| Прочие Linux x64 | Портативный архив (нужны GTK 3 и WebKitGTK 4.1) | `*-linux-amd64.tar.gz` |

> [!WARNING] SmartScreen в Windows
> Ранние неподписанные сборки могут вызывать предупреждение Microsoft Defender SmartScreen. Скачивайте Waxlight только со страницы Releases официального репозитория. Подробнее — в разделе [«Подпись кода»](./policies/code-signing.md).

## Проверка целостности

Сравните SHA-256 скачанного файла со значением из `SHA256SUMS`:

```bash
# Linux
sha256sum -c SHA256SUMS --ignore-missing

# Windows (PowerShell)
Get-FileHash .\waxlight-*-windows-amd64-installer.exe -Algorithm SHA256
```

SHA-256 подтверждает, что файл побайтово совпадает с артефактом релиза, но **не удостоверяет издателя**. Для этого служит Authenticode-подпись — см. [политику подписи кода](./policies/code-signing.md).

## Первые шаги

1. **Войдите в аккаунт.** Откройте раздел «Аккаунты» и войдите с учётной записью Vintage Story. Поддерживается TOTP/2FA. Подробнее — [Аккаунты и вход](./features/accounts.md).
2. **Установите версию игры.** Раздел «Версии игры» → выберите версию → «Скачать». Прогресс виден на странице [«Операции»](./features/operations.md).
3. **Создайте инстанс.** В «Библиотеке» создайте инстанс и выберите для него аккаунт и версию игры.
4. **Установите моды (по желанию).** Раздел «Моды» — встроенный браузер Vintage Story ModDB с поиском и фильтрами.
5. **Нажмите «Играть».** Для игры требуется действующий аккаунт Vintage Story с доступом к игре.

## Где хранятся данные

| Платформа | Каталог по умолчанию |
| --- | --- |
| Linux | `~/.config/waxlight/` |
| Windows | `%AppData%\waxlight\` |

Внутри — версии игры (`versions`), инстансы (`instances`), загрузки (`downloads`), кэш (`cache`), бэкапы (`backups`), журналы (`logs`) и база данных лаунчера. Основной каталог можно перенести в другое место: **Настройки → Папка данных**. Учётные данные аккаунтов при этом остаются в системном хранилище ОС.

## Телеметрия при первом запуске

Опциональная телеметрия **выключена по умолчанию**. В Windows-установщике показывается политика конфиденциальности и отдельный, по умолчанию снятый, флажок согласия. Настройку можно изменить в любой момент: **Настройки → Конфиденциальность и телеметрия**. Полный список передаваемых полей — в [политике конфиденциальности](./policies/privacy.md).
