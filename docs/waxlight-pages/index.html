Waxlight

A focused launcher for Vintage Story

◫

Isolated setups

Create independent game environments so mods and settings never leak between setups.

♙

Multiple accounts

Manage several Vintage Story accounts, including TOTP/2FA authentication.

⬡

Game versions

Install multiple official game versions side by side and select one for each setup.

◇

Mod browser

Browse Vintage Story ModDB with search, filters, sorting, and detailed mod pages.

⇣

Downloads and operations

Track progress, cancel operations, resume where possible, and validate checksums.

◷

Playtime statistics

Track individual sessions, total playtime, and statistics for each setup.

First launch

Open Accounts and sign in with a Vintage Story account.
Install a supported version from Game Versions.
Create a setup in Library and select its account and game version.
Optionally install mods.
Select the setup and press Play.
Security

Security and privacy

Passwords and TOTP codes are never persisted. Persistent session credentials use Secret Service on Linux and Windows Credential Manager on Windows. React receives allow-listed DTOs and cannot access raw session credentials.
