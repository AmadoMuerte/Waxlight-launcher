One launcher. Many worlds.
Built for a long journey

Everything around the game, kept together.

Waxlight helps you create a calm, repeatable space for every version, mod setup, and world you return to.

01

Accounts and 2FA

Manage multiple Vintage Story accounts with TOTP/2FA support and protected native credential storage.

02

Game versions

Install supported game versions side by side and choose the right one for every instance.

03

Isolated instances

Give each playthrough its own settings, mods, game version, launch arguments, and identity.

04

ModDB in the launcher

Browse Vintage Story ModDB, search and filter mods, then manage them directly per instance.

05

Mod management

Install, update, enable, disable, remove, and batch-install mods without leaving your library.

06

Backups and recovery

Create snapshots, receive safety backups before changes, and restore a known-good instance after trouble.

07

Shareable packages

Export and import Waxlight packages for instances while sanitizing authentication and private machine data.

08

Downloads and operations

Follow long-running work, inspect progress, cancel operations, and validate downloaded files.

09

Playtime and logs

Keep track of sessions and playtime, with launcher logs and a redacted support-log export when needed.

10

Updates you control

Choose stable or prerelease channels and verify release downloads with published SHA-256 checksums.

11

Your data folder

Move Waxlight data to a location you choose without mixing it with the game itself.

12

Ten interface languages

Use English, Русский, Беларуская, Español, Français, Deutsch, Қазақша, Polski, Svenska, or Português.

Security and privacy

Your credentials stay yours.

Passwords and TOTP codes are never persisted. Persistent session credentials use Secret Service on Linux and Windows Credential Manager on Windows. Optional telemetry is disabled by default and can be changed later in Settings.
