GitHub Releases

Первый запуск

Откройте «Аккаунты» и войдите в аккаунт Vintage Story.
Установите поддерживаемую версию в разделе «Версии игры».
Создайте сборку в «Библиотеке» и выберите аккаунт и версию.
При необходимости установите моды.
Выберите сборку и нажмите «Запустить».
Security

Безопасность и приватность

Пароли и TOTP-коды никогда не сохраняются. Постоянные данные сессий хранятся через Secret Service в Linux и Windows Credential Manager в Windows. React получает только разрешённые DTO и не имеет доступа к исходным данным сессии.
